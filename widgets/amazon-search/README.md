# Amazon Australia Search Widget

Custom Amazon Australia affiliate search widget used on **aukihenry.com**.

## Purpose

This widget provides a simple Amazon Australia product search box for the aukihenry.com sidebar.

It is intentionally lightweight:

- no external JavaScript
- no third-party widget framework
- no tracking library beyond the normal Amazon destination URL
- styling is hosted on this GitHub Pages repository
- Blogger only contains the small HTML form markup
